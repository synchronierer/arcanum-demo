# Arcanum DEMO

Arcanum is a learning environment where students see subjects, stages, coins,
and their current learning progress.

Open the [public DEMO](https://arcanum-demo.dynv6.net/login), preferably on a
laptop or tablet, and start with the
[German beginner student tour](docs/handbuch.de.md). It uses the synthetic
grade-6 account Anton Apfel; the public login name is in the
[credentials PDF](Arcanum_DEMO_Zugangsdaten.pdf). Passwords are intentionally
not repeated in screenshots or this page.

The DEMO contains fictional data and is shared. Changes made by other visitors
may be visible.

The tested views support 768 px, 1024 px, and 1440 px. At 390 px there is a
known accepted page-overflow limitation. The German guide is currently the
detailed walkthrough; this English document is not a translation-equivalent.
