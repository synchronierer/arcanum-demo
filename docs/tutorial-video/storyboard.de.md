# Storyboard: Arcanum DEMO – Schüler-Rundgang

Ziel: etwa 5–8 Minuten, 1440×900, ruhige Bildschirmaufnahmen aus der echten
DEMO. Keine sichtbare Passworteingabe.

| Zeit | Bild | Kernaussage |
|---:|---|---|
| 0:00–0:25 | Login | Arcanum zeigt Lernweg und Fortschritt. |
| 0:25–1:05 | Dashboard oben | Name, Klasse, Graduierung, Rang, Avatar. |
| 1:05–1:45 | Dashboard/Fachkarte | Fachkarten verbinden Arbeit, Münzen und Note. |
| 1:45–2:20 | Mathematik | Münzen, aktuelle Note und Prognose unterscheiden. |
| 2:20–2:55 | Aktionsbereich | Hilfe, Partner, Experiment, Gelingensnachweis sind Meldungen. |
| 2:55–3:35 | Offen/Aktuell/Bestanden/Gesperrt | Statusgruppen erklären. |
| 3:35–4:15 | Themen und Etappen | Thema, Niveau, Titel und Münzen. |
| 4:15–4:45 | WPF-Karte | Individuelles Fach gehört nur zu diesem Schüler. |
| 4:45–5:55 | Schatzkammer | Fachbeiträge, Münzstapel bis 100, Notenmarkierungen und Erfolgslogbuch. |
| 5:55–6:20 | Rückkehr Dashboard | Dashboard, Fachkarte und Schatzkammer zusammenfassen. |

Die Bilder in `docs/images/student-tour/` sind die realen Quellen für den
Prototyp. Die Anwendung wird nicht verändert.
