# Arcanum DEMO — English status

The current detailed beginner walkthrough is the
[German student tour](handbuch.de.md). It uses the live synthetic grade-6
account Anton Apfel and the real screenshots in `images/student-tour/`.

The public DEMO is shared and contains fictional data. A laptop or tablet is
recommended. Views were checked at 768 px, 1024 px, and 1440 px. At 390 px
horizontal scrolling may currently occur on very narrow smartphone displays;
a fully supported smartphone layout is not claimed.

The current DEMO exposes only subjects that are currently used and have at
least one current-semester stage. Individual subjects appear only when assigned
to that synthetic student. The separate
[teacher and administration guide](lehrkraft-und-administration.de.md) follows
the student-first tour.
